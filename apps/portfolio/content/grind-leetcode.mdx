# Arrays

## Basics: Initialization & Basic Operations

```cpp
int arr[5]; // fill in with 0s by default
int arr[5] = {1, 2, 3}; // same as above
int arr[] = {1, 2, 3, 4, 5}; // or automatically allocate spaces

arr[0] = 10;
int x = arr[1];
```

```cpp
#include <vector>

vector<int> nums; // empty
vector<vector<int>> numsInNums;
vector<int> nums(5); // {0, 0, 0, 0, 0} - same as above
vector<int> nums(5, 10); // {10, 10, 10, 10, 10}
vector<int> nums = {1,2,3,4}; // or nums{1,2,3,4} for short

int arr[] = {1,2,3};
vector<int> nums(arr, arr+3); // use array for ini.

vector<int> v;

v.push_back(10);
v.insert(v.begin(), 5); // insert 5 as the 1st element

v.pop_back(); 
v.clear();

v[0] = 100;
v.at(0) = 100;
int x = v.front();
int y = v.back();

v.size(); // return the number of elements
v.empty(); // is it empty or not?
v.resize(10);

for(int x : v) cout << x;
```
